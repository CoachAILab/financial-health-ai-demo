# 🏦 Financial Health AI · Demo

> Prototipo funcional de un módulo de diagnóstico financiero personalizado para banca retail, impulsado por inteligencia artificial.

---

## ¿Qué es esto?

**Financial Health AI** es una demo de una funcionalidad diseñada para integrarse en aplicaciones bancarias móviles o web. El sistema analiza los datos financieros reales de cada cliente — ingresos, gastos, ahorro y deuda — y genera automáticamente un diagnóstico personalizado con recomendaciones accionables, usando modelos de IA.

El objetivo es transformar datos transaccionales en una experiencia comprensible y útil para el usuario, ayudándole a entender su salud financiera y tomar mejores decisiones.

---

## Funcionalidades del prototipo

- **Coach IA** — Diagnóstico automático con resumen ejecutivo, fortalezas, áreas de mejora y recomendación principal generados por IA
- **Ingresos y gastos detallados** — Desglose por período (1M / 3M / 6M / 12M) con fuentes de ingreso y top gastos prescindibles
- **Tendencias** — Indicadores visuales de tendencia por categoría (Estable / Creciente / Ascendente)
- **Alertas activas** — Sistema de alertas priorizadas (Alta / Media / Baja) basadas en el comportamiento financiero del cliente
- **Salud financiera** — Tarjetas con evolución del colchón financiero, balance mensual y gasto en ocio
- **Multi-cliente** — Navegación entre perfiles de distintos clientes desde un mismo panel
- **Diseño mobile-first** — Interfaz optimizada para dispositivos móviles con estética de app bancaria

## Contexto

Este prototipo forma parte de una iniciativa de innovación en experiencia de cliente bancario. El módulo está diseñado para conectarse con el core bancario a través de una API que expone los movimientos categorizados del cliente, y con un modelo de lenguaje (LLM) que genera el diagnóstico en lenguaje natural.
